# Дипломная работа Нетология

## О проекте

Сайт для бронирования билетов в кинотеатр с административной панелью.

## Стек технологий

- React
- React Router
- Vite
- CSS (БЭМ)
- JavaScript

## Запуск проекта

1. npm install
2. npm run dev
3. Открыть http://localhost:5173
